# 11 — Deployment

Last reviewed: 2026-09-04

## Image

- Scratch static binary, UID/GID `65532:65532`.
- Exec-form HEALTHCHECK:
  `/labsyslog healthcheck --url=http://127.0.0.1:8088/v1/health/ready`
- CMD: `serve --config=/etc/labsyslog/config.yaml --management-listen=:8088`
- Read-only rootfs, tmpfs `/tmp`, `cap_drop: ALL`,
  `no-new-privileges`.
- Config at `/etc/labsyslog/config.yaml`. Token at
  `/run/secrets/labsyslog-token`.

## Ports

| Plane | Container | Host default | Native dest |
|---|---|---|---|
| syslog UDP | 514/udp | 10514 | 514 |
| syslog TCP | 514/tcp | 10514 | 514 |
| management | 8088/tcp | 18514 | n/a |
| syslog TLS | 6514/tcp | not published in 1.0 | 6514 |

10514 is residual-as-default because rsyslog/journald often hold
514. It is not the design. Operator escape:
`LABSYSLOG_SYSLOG_PORT=514` after preflight.

Local tests use `:1514` and never request `NET_BIND_SERVICE`.
Integrator compose adds `NET_BIND_SERVICE` because the container
process binds `:514` (ADR 0010).

## NAT collision

Docker `userland-proxy: true` SNATs UDP source addresses. Per-IP
admission (`allowClientCidrs`, `maxDatagramsPerIP`) and filters that
match `sourceCidrs` other than the compose gateway are best-effort on
host-publish UDP: the appliance sees the proxy source-IP, not the
client. Reliable path: clients on `mcplab-shared`. Do not add a Go
userland-proxy probe (LabNTP ADR 0014 class). Document the collision;
fail closed only on port occupancy.
