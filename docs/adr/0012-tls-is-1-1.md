# ADR 0012 — RFC 5425 TLS is v1.1

- Status: Accepted
- Date: 2026-09-04

## Context

RFC 5425 syslog-over-TLS on dest 6514 is real SUT traffic. LabMail
deferred implicit SMTPS. LabNTP deferred NTS. Shipping TLS in 1.0
would couple the first tag to PKI layout and origin policy.

## Decision

- Schema key `spec.listeners.tls` exists so documents do not churn.
- `enabled: true` is a validate error in 1.0 (`tls_unsupported`).
- No 6514 publish in the default lab profile.
- TLS-001 is a follow-on wave after GA. Same in-tree server, not a
  sidecar.

## Consequences

Agents must not implement a TLS listener in 1.0 waves. Tests lock
the reject.
