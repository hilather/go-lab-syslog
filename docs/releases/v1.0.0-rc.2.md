# LabSyslog v1.0.0-rc.2

Release-candidate notes for the 1.0 surface. This tags `v1.0.0-rc.2`
on top of `v1.0.0-rc.1`. It is **not** a `v1.0.0` tag.

Do **not** tag `v1.0.0` until [../reviews/mira-ui-001.md](../reviews/mira-ui-001.md)
records a Mira review outcome for UI-001. That file is still a
placeholder and is **not** an approval. Mira can review after this RC.

TLS-001 (RFC 5425) is v1.1 and must not reopen this release.
The integrator vendor pin is a follow-on after the first `v*` tag.

## What ships

Fixes since `v1.0.0-rc.1`. Go toolchain go1.26.9 (`go.mod` toolchain,
CI `GO_VERSION`, Dockerfile); 1.26.0–1.26.8 lack current stdlib
security fixes (GO-2026-6603..6617). `golang.org/x/sys` v0.47.0, past
GO-2026-5024. Web development dependency `source-map-js` 1.2.2
(GHSA-68fv-2mgg-jv7q); lockfile only, built web assets byte-identical.

`labsyslog mcp-stdio` re-authenticates the bearer read from
`--token-file` on every tool and resource call. REST `changes:plan`,
`changes:apply`, `state:reset`, `messages:clear`, and `messages:wait`
reject a second JSON value before the operation. `GET /v1/events/stream`
closes when the cookie session is gone or the bearer no longer grants
`syslog.read`. Reset that changes the effective management address
returns `validation_failed` and keeps the HTTP listener from process
start. `POST /v1/session` and `GET /v1/session` send
`Cache-Control: no-store`. Successful apply keeps at most 128
idempotency records.

## Residual limits

See [../known-limitations.md](../known-limitations.md). In short:
no TLS listener, no RELP, no persistence, no HA, no OAuth, NAT
collision on host-published UDP, `Message.Truncated` always false.

## Required CI on the tag SHA

format, lint, unit, race, fuzz-smoke, documentation, changelog,
generated, config-compat, import-fence (Dial AST + forbidden-module
AST in `internal/testutil/fence_test.go`), security-scan,
container-test, parity, web.

Fuzz seeds live under `testdata/corpus/{syslogwire,syslogframing}`.
Soak: 10k UDP/s for 60s on a test bind; store caps hold; no leak.
